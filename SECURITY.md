# Security Policy

## Supported versions

We support the latest release tag of `hypermile-audit`.

## Reporting a vulnerability

Please email **hello@hypermile.dev** with a description of the issue.
Do not open a public GitHub issue for security reports.

This tool only reads local Claude Code transcripts. If you find a way it could
exfiltrate data, execute untrusted content from transcripts, or otherwise leave
the machine, that is a priority-1 report.
